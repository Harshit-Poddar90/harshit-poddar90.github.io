04 — Projects

Things I've built

Flagship

PatchPilot — autonomous code-healing agent

A LangGraph state machine that runs a Python program, intercepts the traceback, and either returns a verified past fix from semantic memory (pgvector, similarity > 0.90) or asks Gemini 2.5 Flash for a patch — so an already-solved bug costs no LLM call. A human-in-the-loop gate guards every file write; the fix is re-executed and written back as new memory. MLflow traces every prompt, token count and node latency.

  • Semantic fix cache
  • Human-in-the-loop
  • Full run tracing
  • LangGraph
  • Gemini API
  • Supabase / pgvector
  • MLflow
  • Streamlit
IEEE SENNET 2025

LungMate — lung-cancer detection with quantitative assessment

Hybrid detector replacing the YOLOv11s backbone with EfficientNet-B3 + Swin Transformer + CBAM, trained on 6,789 annotated CT scans across four lung-cancer classes. Tumour diameter, area, perimeter, volume and mass are derived from 2D bounding boxes via a calibrated pixel-to-cm factor, removing the need for 3D reconstruction. Shipped as a PyQt5 desktop tool with 15 image-processing modes.

  • 91.05% mAP@0.5
  • 90.12% precision
  • 2.35 ms inference
  • PyTorch
  • EfficientNet-B3
  • Swin + CBAM
  • YOLOv11
  • OpenCV
  • PyQt5
  • DICOM
