01 — Intro

About

I work on the engineering side of AI: turning research-grade models into systems other people can actually run. Right now that means agentic LLM orchestration — decomposing a manual pipeline into tool-calling agents behind typed FastAPI endpoints, with validation, fallback routing and run tracing so every output is reproducible and auditable.

04 — Projects

Things I've built

Flagship

PatchPilot — autonomous code-healing agent

A LangGraph state machine that runs a Python program, intercepts the traceback, and either returns a verified past fix from semantic memory (pgvector, similarity > 0.90) or asks Gemini 2.5 Flash for a patch — so an already-solved bug costs no LLM call. A human-in-the-loop gate guards every file write; the fix is re-executed and written back as new memory. MLflow traces every prompt, token count and node latency.

  • Semantic fix cache
  • Human-in-the-loop
  • Full run tracing
  • LangGraph
  • Gemini API
  • Supabase / pgvector
  • MLflow
  • Streamlit

Ask the Bank — text-to-SQL over a 1M-row database

Plain-English questions over a real Czech bank's 1,084,180 rows. BM25, embeddings and a value index pick the relevant tables; the LLM writes SQL from five retrieved examples; a syntax-tree validator rejects anything but a single read-only SELECT before it reaches a read-only database. Failed queries are repaired from the exact error, and every question is audit-logged with its SQL, timings and cost.

  • Read-only by design
  • Self-repair loop
  • 70-question benchmark
  • Python
  • FastAPI
  • sqlglot
  • SQLite
  • Gemini / OpenAI / Ollama
  • Streamlit
  • Docker
IEEE SENNET 2025

LungMate — lung-cancer detection with quantitative assessment

Hybrid detector replacing the YOLOv11s backbone with EfficientNet-B3 + Swin Transformer + CBAM, trained on 6,789 annotated CT scans across four lung-cancer classes. Tumour diameter, area, perimeter, volume and mass are derived from 2D bounding boxes via a calibrated pixel-to-cm factor, removing the need for 3D reconstruction. Shipped as a PyQt5 desktop tool with 15 image-processing modes.

  • 91.05% mAP@0.5
  • 90.12% precision
  • 2.35 ms inference

  • EfficientNet-B3
  • Swin + CBAM

KTH course project

Constrained Flow Matching for vehicle trajectories

When should physical rules enter a generative model's sampling? A conditional Flow Matching model predicts 6-second futures for cars at an Aachen intersection, trained on 14,540 windows of inD drone data. Without rules, 28% of futures leave the road; soft guidance brings 99.9% within road, speed and acceleration limits without the 2–5× jerk that hard projection adds. Data and aerial imagery: inD dataset (Bock et al., IEEE IV 2020), shown here for non-commercial illustration.

  • 99.9% rule-feasible
  • 4 strategies compared
  • PyTorch
  • Flow Matching
  • Generative models
  • Trajectory prediction
  • inD dataset
KTH course project

Rhythm or just tempo? Stress-testing a dance classifier

Do ballroom-dance classifiers learn the style, or just the speed? Models trained on 698 clips across 8 dances are tested on the same music time-stretched by up to ±10%, pitch unchanged. Rhythm features fall from 82% to 18% macro-F1 at +10% tempo; timbral features (MFCC, zero-crossing rate, spectral centroid, written from scratch in NumPy) barely move. Timbre plus tempo-free rhythm still holds 66–70%.

  • ±10% time-stretch test
  • Nested 5-fold CV
  • Python
  • NumPy
  • librosa
  • scikit-learn
  • Random Forest / SVM
